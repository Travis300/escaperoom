# Nittany Bets

Penn State themed mock sports betting application built with Flask and SQLite.

## Features
- Account creation and login
- Virtual wallet with mock bets on Penn State games
- Leaderboards, bet history, daily bonus, achievements, trivia

## Setup
1. Install dependencies:
   ```
   pip install flask
   ```
2. Run the application:
   ```
   python app.py
   ```
   The database initializes on first run with sample games, achievements and trivia.
